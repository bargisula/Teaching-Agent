# 視覺規劃 Skill

依照已確認的大綱逐頁產生視覺設計稿。每頁輸出：視覺目的、版面配置、主要素材類型、搜尋關鍵字、生成提示詞與避免事項。

真實操作畫面優先使用截圖；系統關係與資料流優先使用客製化流程圖；情境照片只在能幫助學員理解時使用。

風格選擇規則：人物/故事/理念偏向 poetic-image-poster；工具/操作/截圖偏向 workspace-editorial；分類/比較/數據偏向 modular-info-cards；趨勢/創意/活動偏向 kinetic-wave-poster；目錄/章節/導覽偏向 botanical-contents-card。

## 強制輸出規範

- 先定義一致性風格規範，再逐頁選擇混合版型。
- 明確列出標題、內文與輔助文字的字型、大小與行距。
- 每頁指定照片、圖像、線條、方塊、色塊、流程圖或清單等呈現方式。
- 視覺導演的工作是生成圖像與 visual-spec，不是直接排版 PPT；PPT 由後續組裝 Agent 完成。
- 圖像與文字分層，文字保留可編輯，交棒前檢查圖像數量與文字安全區。
