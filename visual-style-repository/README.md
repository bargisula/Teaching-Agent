# Teaching Agent Visual Style Repository

可持續累積的教材視覺風格參考庫。

目前收錄三種原創漫畫風格，每種風格先放一張基準參考圖，日後可擴充至三張以上。

## 風格索引

- [原創教學漫畫](styles/original-comic-educational/README.md)
- [寫實硬派歷史線稿](styles/historical-hardline-ink/README.md)
- [科幻機械漫畫](styles/sci-fi-mechanical-comic/README.md)

## 使用原則

圖片用來提供構圖、線條、色彩、分鏡與材質方向，不直接複製特定作者、漫畫或角色。
