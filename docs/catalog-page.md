# 教材管理頁面規格

## 頁面唯一任務

讓使用者在幾秒內找到一套教材，知道目前狀態與最新版本，並直接進入指定版本繼續工作。

## 第一版資訊架構

```text
教材庫
├─ 搜尋列：名稱、標籤、內容關鍵字
├─ 篩選：狀態、受眾、更新時間、標籤
├─ 教材列表：名稱、描述、標籤、最新版本、狀態、更新時間
└─ 教材詳情：需求摘要、版本時間軸、成果、審查紀錄、新版本入口
```

## 視覺方向

介面以「教材編輯室」為主題，像工作桌上的課程卡片與版本標籤，而不是一般 SaaS 儀表板。使用紙張白、墨黑、深靛藍與暖橘色狀態色；以細線、版本標籤與文件縮圖建立辨識度，避免漸層、霓虹科技背景與泛用統計卡片。

第一個視覺焦點是「最近更新的教材版本」，讓使用者回到上次工作的位置。

## 搜尋與版本行為

- 搜尋比對教材名稱、描述、標籤、受眾與版本內標題。
- 預設最新更新在前，並清楚標示版本狀態。
- 點擊教材進入詳情頁；點擊版本直接進入版本工作區。
- 建立新版本時顯示來源版本與修改原因。
- 沒有結果時，提供可嘗試的標籤與建立新教材入口。

## 驗收條件

- 能以名稱或標籤找到教材。
- 能分辨草稿、審查中與已發布版本。
- 能查看版本歷史，且舊版本仍可開啟。
- 頁面資料來自 `library/_index/catalog.json`，而非散落的輸出資料夾。
