# image-generator Skill

## 使用時機

當課程需要封面圖、概念圖、流程圖、示意圖或其他視覺化內容時使用。

## 輸入

課程主題、對應單元或投影片訊息、想傳達的教學概念。

## 執行步驟

1. 判斷是否真的需要圖像。
2. 選擇照片、插圖、流程圖或概念圖等類型。
3. 設計畫面構圖與文字安全區。
4. 產生圖像生成提示詞與負面提示詞。
5. 說明圖片如何支援教學目標。

## 輸出

- 對應單元或投影片
- 圖片用途
- 圖片類型
- 畫面描述
- 構圖方式
- 圖像生成提示詞
- 負面提示詞
- 教學目的

## 限制與檢查

本 Skill 預設產出圖片規劃與提示詞。若環境沒有真正可用的圖像生成工具，不得宣稱圖片已生成；應明確標示需要外部工具。
