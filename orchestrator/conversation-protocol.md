# Teaching Agent 對話確認協定

## 三個獨立確認狀態

```json
{"requirements":"pending","content":"pending","visual":"pending"}
```

## 正確順序

1. 先提出需求與教學目標草案，等待確認 requirements。
2. 確認 requirements 後，才產出教材大綱與逐頁內容。
3. 產出內容後，等待確認 content。
4. 確認 content 後，才產出視覺規格與圖像提示詞。
5. 產出視覺規格後，等待確認 visual。
6. 確認 visual 後，才可生成圖像、Render 與組裝 PPTX。

## 確認語意

- 需求確認只確認對象、目標、形式、張數、語言與限制。
- 內容確認只確認教學主線、逐頁內容與教學順序。
- 視覺確認只確認風格、構圖、文字呈現與圖像方向。
- 使用者只確認其中一項時，只更新該項，不得替其他項目視為確認。

## 強制停止

缺少前置確認時，不生成下一階段產物、不生成圖像、不組裝 PPTX，並回報待確認項目。
